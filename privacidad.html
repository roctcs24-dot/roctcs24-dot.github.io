Política de privacidad

Publicador Estudio Canales · última actualización: 29 de octubre de 2026 · inicio

1. Quién usa la herramienta

Publicador Estudio Canales es una herramienta privada. Solo la usa el dueño de los canales Electrón Libre y Free Electron Lab, con las cuentas de Google de esos dos canales. No tiene usuarios externos.

2. Qué datos de Google usa y para qué

Con el permiso que da el dueño de cada canal en la pantalla de Google, la herramienta usa la API de datos de YouTube solo para:

  • leer el nombre del canal autorizado, para comprobar que es el canal correcto;
  • subir los videos del propio canal y ponerles título, descripción, etiquetas, portada, categoría y fecha de publicación;
  • añadirlos a las listas de reproducción del propio canal y subir sus subtítulos;
  • escribir el comentario del propio canal en sus videos;
  • buscar entre los videos recientes del canal para no subir dos veces el mismo, y borrar únicamente un video que la propia herramienta acaba de subir por error y que todavía no es público.

No lee ni usa datos de otras personas (espectadores, suscriptores u otros canales).

3. Dónde se guardan

El permiso de Google (token) se guarda solo en la computadora del dueño de los canales. No se envía a ningún servidor propio ni a terceros. Los videos y textos que se suben ya están en esa misma computadora.

4. Con quién se comparten

Con nadie. Los datos solo viajan entre la computadora del dueño y los servicios de Google/YouTube. No se venden, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

5. Cómo retirar el permiso

El permiso se puede retirar en cualquier momento desde la página de Google myaccount.google.com/permissions. Al retirarlo, la herramienta deja de tener acceso y se puede borrar el token guardado en la computadora.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La herramienta usa los servicios de la API de YouTube y acepta las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Privacy policy

Studio Channels Publisher is a private tool used only by the owner of the Electrón Libre and Free Electron Lab channels, with those channels' own Google accounts. With the permission granted on Google's consent screen it uses the YouTube Data API only to read the authorized channel's name, upload that channel's own videos and set their metadata, thumbnail and publish date, add them to the channel's playlists, upload captions, post the channel's own comments, look up the channel's recent uploads to avoid duplicates, and delete only a video it has just uploaded by mistake that is not yet public. It does not access other people's data.

The Google token is stored only on the channel owner's computer and is never sent to any other server or shared with anyone. Data is not sold, not used for advertising and not used to train AI models. Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services and agrees to the YouTube Terms of Service and the Google Privacy Policy.
